# js/ — основной скрипт листа игрока

Бывший один инлайн-`<script>` в `index.html` (~16,5 тыс. строк), разрезанный на файлы по темам. Код не менялся: склейка файлов 01–15 по порядку совпадает с прежним скриптом символ в символ.

**Порядок загрузки важен** (`index.html` подключает файлы подряд, как классические скрипты с общей глобальной областью). Не переставляйте файлы и не добавляйте `type="module"`.

| Файл | Что внутри |
|---|---|
| 01-core-origin | навыки, характеристики, раса и знак |
| 02-powers-time | особые способности, время суток, погода, сбор ингредиентов, билды |
| 03-creation-spells | создание персонажа, книга заклинаний, штрафы к броскам |
| 04-spell-casting | колдовство, призыв, духи оружия, свитки, расходники |
| 05-inventory | инвентарь, нормализация оружия |
| 06-trade-merchants | торговля, живые торговцы |
| 07-craft-enchant-equip | плавка, ковка, зачарование, посохи, экипировка |
| 08-equipment-guilds | экипировка, гильдии, тренировки |
| 09-combat-grid | бой, яды, боевая сетка |
| 10-resist-gear-fish-hunt | сопротивления, текстовые бонусы экипировки, рыбалка, охота |
| 11-session-trade-map | сессия, обмен между игроками, карты, групповые проверки |
| 12-supernatural-lich | оборотень, вампир, вампир-лорд, лич |
| 13-spell-damage-update | урон заклинаний, стены, `updateAll` |
| 14-diary-death-combat | дневник, смерть и жизни, `updateCombat`, руки, питомцы, правки мастера |
| 15-traps-boot | ловушки, загрузка, защита от тюрьмы (должен идти последним) |

Проверка порядка: `15-traps-boot.js` в конце оборачивает функции из предыдущих файлов, поэтому его нельзя ставить раньше.
